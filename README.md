# Card-Game
This project focuses on implementing a Spades card game using Java. The goal is to create a playable game that follows the traditional rules of Spades, including dealing cards, bidding, playing tricks, and keeping score. The project will demonstrate object-oriented programming concepts, game logic, and the use of Java classes and methods. 
Contributors include: Ana Gonzalez Hiraldo, Ashley Forte, and Alixx Cheney
